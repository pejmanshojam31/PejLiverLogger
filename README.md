# 🥃 LiverLogger

A private, offline, one-tap drink tracker that installs on your iPhone home screen like a real app — no App Store, no account, no server, no ads. Everything stays on your phone.

## Features

- **One-tap logging.** Quick-add buttons for your usual drinks (Beer 330/400/500 mL, Wine 100/150 mL, Shots 20/40 mL, Cocktail 250 mL) — tap once, it's logged with a timestamp. Add a custom amount + ABV for anything else, and optionally save it as a new quick-add button.
- **Accurate math.** Every entry is converted to grams of pure alcohol using the standard formula (`mL × ABV% × 0.789`), the same one NIAAA and most standard-drink calculators use. Displayed as US standard drinks (14g), UK units (8g), or German Standardglas (~11g) — your choice.
- **Charts.** Last 7 days, a 10-week trend against published guideline reference lines, a by-drink-type breakdown, and a 5-week calendar heatmap with your current alcohol-free streak.
- **Research-backed Info tab.** Plain-language summaries of the WHO's 2023 "no safe level" statement, the US Surgeon General's January 2025 cancer advisory, the 2025–2030 US Dietary Guidelines update, the UK CMO's 14-units guideline, and Germany's DHS guidance — each with a source link. Bilingual, English/German.
- **Fully offline & private.** A service worker caches the whole app on first load, so it works with no signal. All data lives in the browser's local storage on your phone only — nothing is ever sent anywhere. Export/import as JSON for your own backups.
- **Bilingual.** Toggle English ⇄ German in Settings.

This is not medical advice. It's a personal tracking tool. If you're worried about your drinking, please talk to a doctor.

## Install on iPhone

1. Open this repo's GitHub Pages URL in **Safari** on your iPhone (Settings → Pages, see below, or ask whoever set this up for the link).
2. Tap the **Share** button (square with an arrow).
3. Tap **Add to Home Screen** → **Add**.
4. Open it from your home screen from then on — it runs full-screen, no browser bar, and works offline.

Your data is stored per-installation in that home-screen app's own storage. It survives normal use; if you ever delete the app from your home screen, its data goes with it — so export a backup from Settings → Your data every so often.

## Hosting it yourself (GitHub Pages)

```
git remote add origin https://github.com/<you>/LiverLogger.git
git push -u origin main
```

Then in the repo on GitHub: **Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)` → Save.** GitHub gives you a `https://<you>.github.io/LiverLogger/` URL a minute later — that's the link to open in Safari and add to your home screen. The app's code is public on that URL, but that's just the empty app shell; nobody sees your drink log, because it never leaves your phone's local storage.

## Project structure

```
index.html            single-page app shell, all four tabs
styles.css             dark, mobile-first styling
logic.js               pure calculation functions (grams, units, streaks, aggregation) — no DOM, unit-tested
i18n.js                English/German UI strings + the Info tab's research content
app.js                 wires storage, presets, logging, charts, settings to the DOM
chart.umd.min.js       Chart.js, bundled locally (no CDN — needed for true offline use)
manifest.webmanifest   PWA metadata (name, icons, standalone display)
service-worker.js      offline cache-first app shell
icons/                 app icons (generated by gen_icons.py, no external assets)
gen_icons.py           regenerates icons/ from scratch with Pillow
logic.test.js          `node logic.test.js` — checks the alcohol-content math against NIAAA's own reference drink sizes
```

## Running the tests

```
node logic.test.js
```

Cross-checks the gram calculations against NIAAA's published reference drinks (355 mL beer @5%, 148 mL wine @12%, 44 mL spirits @40% ≈ 14g each) plus the date/streak/aggregation logic.
